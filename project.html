    Why this matters

    Phishing attacks often use misleading domains, urgent words, insecure connections, and hidden redirects to trick you. This website helps you identify those risks before you click.

    • Find fake domains and impersonation attempts.
    • Spot insecure HTTP links and IP-based URLs.
    • Learn how cybercriminals hide malicious pages.

    How PhishGuard assesses risk

    Each URL is scored using a set of safety checks. The tool flags suspicious domains, unusual characters, weak protocols, and phishing-themed words.

    • Checks for hidden username sections using @.
    • Detects non-secure http:// links.
    • Flags direct IP addresses instead of real domains.
    • Looks for dangerous top-level domains like .xyz and .top.

    Common phishing indicators

    • Many subdomains or extra hyphens in the address.
    • Brand names used in a suspicious domain structure.
    • Urgent terms such as login, verify, or account.
    • Unexpected file downloads on login pages.

    Protect yourself

    • Always inspect the full URL before entering credentials.
    • Use two-factor authentication when available.
    • Do not trust links from unknown sources.
    • Bookmark frequently visited login pages.

    Sample suspicious links

    • http://google.com@secure-login.xyz
    • https://paypa1-login.top
    • http://192.168.0.1/verify-account
    • https://online-bank-secure.xyz
